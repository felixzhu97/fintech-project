# E10 — Bonds & Options

## Background

Fixed income and options extend the instrument model for richer portfolios.

## User Stories

### US-21 Bonds

**As an** ops/investor user, **I want** bond resources, **so that** fixed-income holdings can be modeled.

**Acceptance Criteria**

1. GIVEN bond payloads  
   WHEN bond APIs are used  
   THEN bonds persist and link to instruments as designed

### US-22 Options

**As an** ops/investor user, **I want** option resources, **so that** derivatives can be modeled.

**Acceptance Criteria**

1. GIVEN option payloads  
   WHEN option APIs are used  
   THEN options persist per API contract
